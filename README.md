# Worldkiln

**Make it yours.**

**Worldkiln 0.8.5 — Public Beta for Windows**

![Worldkiln castle scene](SCREENSHOTS/Worldkiln_%20Build%20Your%20Fantasy%20Fortress.png)

Build Worlds, create gameplay with AeoScript, and test your game in Play mode. Newer tools are included as **BETA features** while they continue to improve.

[**Download Worldkiln**](https://github.com/Aeowun/Worldkiln/releases) · [Documentation](https://aeowun.com/docs/) · [AeoScript](https://aeowun.com/aeoscript/)

## What's new

- **Redesigned editor** — cleaner workspaces, contextual Properties, and faster access to project settings.
- **Unified Project Explorer** — organize Actors, scripts, and scene objects in your own folders.
- **Expanded Content Browser** — browse assets by folder and drag Actors into your World.
- **Layered Landscaping (BETA)** — generate, sculpt, paint, and manage terrain layers.
- **AI Assistant (BETA)** — work on scripts and project objects with review and revert controls.
- **Particles and effects** — add fire, smoke, and script-controlled emitters to your games.

**and much more!**
